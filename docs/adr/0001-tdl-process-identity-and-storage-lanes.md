# Jalankan TDL sebagai root dengan storage per lane

Worker menjalankan seluruh proses TDL sebagai satu identitas sistem operasi, yaitu root, sambil mempertahankan dua storage Bolt terpisah untuk lane Download dan Export. Pemisahan storage dan lock lane menjaga export dan download tetap dapat berjalan paralel tanpa membuka database yang sama; pemisahan UID tidak memberi manfaat untuk kebutuhan tersebut dan menyebabkan ketidakcocokan permission pada file sementara. Layout fisik `root/.tdl` dan `user1/.tdl`, HOME per lane, serta nama lama pada API dan arsip tetap dipertahankan untuk kompatibilitas. Nama `root` dan `user1` pada layout itu adalah label historis, bukan identitas proses yang menjalankan TDL. Rollback memakai snapshot terverifikasi atas kedua storage beserta permission dan ownership sebelum image lama dipasang kembali.
