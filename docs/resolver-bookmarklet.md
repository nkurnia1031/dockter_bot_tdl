# Bookmarklet Resolver Safelink

Bookmarklet ini dijalankan langsung pada halaman Safelink di desktop Chrome atau Edge. Setiap klik memproses paling banyak satu langkah Livewire; klik lagi setelah halaman berpindah. URL tujuan akhir ditampilkan agar bisa disalin, tanpa membukanya otomatis.

## Memasang

1. Buat bookmark bernama `Resolver Safelink`.
2. Salin seluruh satu baris pada blok di bawah, mulai dari `javascript:`, lalu tempel ke kolom URL/alamat bookmark.
3. Buka URL Safelink dan klik bookmark. Ulangi setelah setiap perpindahan halaman.

Tidak ada allowlist domain: bookmarklet bekerja pada halaman HTTP/HTTPS yang memiliki state dan indikator tahap Livewire yang dikenali. Jika state belum ada, satu pemakaian bookmarklet menjalankan urutan tombol `.step-btn` → `Next` → `.step-btn` berikutnya; setiap tombol diklik sekali, dengan waktu tunggu maksimal 15 detik agar tombol berikutnya muncul. Request Livewire tetap dikirim hanya ke origin halaman aktif; redirect fetch ditolak. Bookmarklet tidak memanggil API TME3Bot, membuat job worker, mengirim URL/sesi ke backend aplikasi, atau mengambil isi URL tujuan. Link tahap berikutnya dibuka sebelum tahap terakhir; URL yang diterima pada tahap terakhir ditampilkan untuk disalin, tidak dibuka otomatis. Jika Cloudflare menampilkan challenge, selesaikan atau tunggu secara normal di browser lalu klik bookmark lagi; bookmarklet tidak melewati challenge atau CAPTCHA.
