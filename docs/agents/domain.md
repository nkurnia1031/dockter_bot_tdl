# Domain Docs

This is a single-context repository. Domain terms and architecture decisions
live at the repository root.

## Before exploring

- Read `GLOSSARY.md` if it exists.
- Read relevant decisions in `docs/adr/` if it exists.
- If either is absent, proceed without requiring it to be created upfront.

## Layout

- `GLOSSARY.md`: project vocabulary.
- `docs/adr/`: architecture decision records.

Use glossary terms consistently in issues, plans, code, and tests. If a needed
term is missing, note the gap for domain modeling. Surface conflicts with an
existing ADR instead of silently overriding it.
